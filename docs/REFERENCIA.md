# Referencia de sintaxis → movida a la skill

La referencia de sintaxis se reorganizó en dos catálogos **buscables y unificados**,
que viven con la skill (fuente canónica):

- **[../skill/COMPONENTES.md](../skill/COMPONENTES.md)** — ficha por componente
  (`R`, `L`, `C`, `Z`, `V`, `TF`, `TP`, `D`, `Q`, opamps, chips, …), con id `cpt-*`.
- **[../skill/PARAMETROS.md](../skill/PARAMETROS.md)** — ficha por **parámetro
  modificable** (dirección, etiquetas `v`/`i`/`f`, `kind`, tierras, globales `;`), con
  id `param-*` / `gl-*`.
- **[../skill/INDICE.md](../skill/INDICE.md)** — despacho intención→id y vocabulario de tags.

Cada ficha tiene un `id:` estable; buscá con `rg "id: cpt-tf" ../skill/COMPONENTES.md`.
Marca de soporte real del fork (✅/⚠️) en cada entrada.
